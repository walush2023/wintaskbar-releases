# WinTaskbar

A Windows-style taskbar for macOS (macOS 14 or later, Apple silicon).

**[Download the latest version](https://github.com/walush2023/wintaskbar-releases/releases/latest/download/WinTaskbar.dmg)** — free 7-day trial.

Every release is signed with a Developer ID and notarized by Apple. Installed copies update themselves
(Settings → Taskbar → Updates).

- `WinTaskbar.dmg` — open it and drag WinTaskbar to Applications
- `WinTaskbar.zip` — the same app, used by the built-in updater
- `SHA256SUMS.txt` — checksums
